# คลังคำพิพากษาคดีแรงงาน

คลังสรุปคำพิพากษาศาลฎีกาและศาลอุทธรณ์คดีชำนัญพิเศษในคดีแรงงาน จัดหมวดตามประเด็นปัญหา จัดทำโดยสำนักงานทนายความและที่ปรึกษากฎหมายพรนารายณ์และเพื่อน

- `index.html` หน้าเว็บ
- `data/cases.json` ข้อมูลสรุปคำพิพากษาทั้งหมด
- `pdf/` หนังสือสรุปคำพิพากษาและสรุปคำพิพากษาประจำเดือนของกองนิติการ กรมสวัสดิการและคุ้มครองแรงงาน
- `img/` รูปประกอบ

เว็บนี้เป็นไฟล์ล้วน ไม่มีฐานข้อมูล วางบนบริการฝากเว็บแบบไฟล์ใดก็ได้
